# Evidence semantics

Execution status, security verdict, legitimate-task outcome, observation coverage and release policy action are separate values. Security PASS without task SUCCESS cannot establish a useful fix. Missing observation yields INCONCLUSIVE/UNKNOWN; it does not prove that a prohibited action did not happen. A confirmed failure survives later transport errors, expired raw traces and sampled passes for the same content identity.

Evidence snapshots retain the property definition digest, observed fingerprint, exact candidate, target and observer identities, run/result references, qualifications, coverage, trial/variant budget, establishment/expiry times, raw references and limitations. Existing evidence is never silently rewritten. Scope review appends a new version. Raw payload expiry does not erase retained evaluation or adverse lineage.

Integration imports are INSTRUMENTED, incomplete and review-required; task outcome remains UNKNOWN. SARIF findings are drafts. Imported component provenance is DECLARED on approval, never automatically OBSERVED. Collector controls and independent business-state witnesses establish qualification through the existing execution plane.

Historical action answers what the policy decided then. Current assessment answers whether the original evidence and authority still support that decision. Historical receipts remain verifiable even after current eligibility is downgraded. Neither a finite trial budget nor a signed receipt establishes universal system safety.
