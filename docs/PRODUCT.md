# Product — Autonomous Change Assurance

ThreatVeil maintains the relationship between an autonomous system’s consequential authority and the evidence that supports it. Autonomous Release Integrity is its initial commercial wedge. Its current wedge is a prepared software agent with consequential tools, explicit permissions and an independently observable business outcome. The product records why a particular candidate was trusted at a particular time.

The new connected journey is Connect → Define → Protect → Baseline → Watch → Decide, with an explicit environment, authority envelope, source freshness and current scoped decision. The complete local Finance Agent path combines three claims, committed business effects and separate acknowledgement. Free, Pro, Team, Business and contract-defined Enterprise share one versioned entitlement engine. Customer target qualification, hosted acceptance and paid conversion remain unproven externally. See [current foundation](CHANGE_ASSURANCE.md) and [commercial definition](COMMERCIAL_PLATFORM.md).

The retained release loop is change → ProofScope → STILL_VALID / VOID / UNKNOWN → bounded re-proof → security verdict plus legitimate-task outcome → ALLOW / WARN / BLOCK → signed receipt → immutable historical ledger. The workspace exposes the release timeline, change explorer, proof obligations, evidence and receipts. Security approval remains a human responsibility.

Integrity Launch packages a scoped installation: one system, reviewed properties, authorized target, collector qualification, initial evidence and a WARN gate. Scope, founder effort and milestones are recorded; only verified payment state counts as paid. Prices require configured commercial scope. Customer onboarding speed, willingness to pay, repeat releases and second-system adoption still require real customers.

The local procurement fixture changes committed SQLite business state. It demonstrates failure, a useful fix, regression, missing observation and a security-only bad fix. It does not establish external customer safety. Fleet assurance, insurance, physical execution and autonomous remediation are future directions, not delivered products.
